Monitor and control

Replaces a dozen tools you keep open

Task Manager, HWiNFO, an FPS counter, netstat, TCPView, Wireshark-lite network views, a port scanner and half of the Windows admin consoles, in one fast page that also works from your phone on the LAN.

Live dashboard

21 widgets you drag, resize, add and remove: CPU per thread, GPU engines, memory, network, disks, temperatures, latency, FPS, top apps, open ports.

History up to a year

Every metric over 15 minutes up to 1 year, kept on disk across restarts, with CSV export.

Process control

Tree and by-app views, live charts per process, loaded DLLs, end, end tree, suspend, priority, CPU affinity, SHA-256 + VirusTotal, block its network.

Sensors and FPS

Every temperature, fan, power rail, clock and voltage as live graphs, plus FPS, 1% lows and frame times for your games. No extra apps to install.

Network

Connections with reverse DNS, listening ports flagged local or exposed, packets per second, ARP neighbors, routes, DNS cache, Wi-Fi, firewall profiles.

Net Lab

Ping, traceroute, DNS lookup and benchmark, TCP port scanner with banners, TLS inspector, HTTP probe with header audit, LAN discovery, Wake-on-LAN.

Dev and containers

node, python, java, bun, deno and databases labelled by what they run (next dev, vite, uvicorn), health checks, Docker and Podman control and logs, WSL.

Windows toolbox

Event logs, installed apps, startup apps, scheduled tasks, drivers, updates, hosts editor, PATH doctor, disk usage, power plans, cleanup, firewall blocks.

Alerts and overlay

Rules on 24 metrics with browser notifications and Discord / Slack / JSON webhooks, a change timeline, and a transparent OBS overlay.

Install

Running in a minute

You need Node.js 18.15 or newer. On Windows the launcher offers to install it for you.

OPTION 1 · EASIEST

Double-click

Download the ZIP, extract it, double-click RigWatch.cmd and click Yes on the admin prompt. Your browser opens the dashboard.

Download ZIP
OPTION 2

Terminal

git clone https://github.com/firas44/RigWatch.git
cd RigWatch
node server.js

Open http://localhost:3000. If the port is busy, RigWatch picks the next free one.

OPTION 3

One single file

The whole app, UI included, in one JavaScript file.

node rigwatch.js
dist/rigwatch.js →
  1. Downloads two helpers from their official releases, pinned and verified by SHA-256: LibreHardwareMonitor (sensors) and Intel PresentMon (FPS).
  2. Asks for admin once. Needed for CPU sensors, FPS, the Security log and firewall blocks. Say no and everything else still works.
  3. Loads 30 days of security history from your event logs so the SIEM is useful from the first minute.

Privacy and safety

Your data stays on your PC

RigWatch is a local web app. It has no telemetry and no cloud.

Local by default

Listens on 127.0.0.1 only. On your LAN other devices get a read-only view; control needs a secret token link.

Hardened web app

DNS-rebinding protection, CSRF checks on every action, a strict Content-Security-Policy, secrets in command lines masked.

Safe actions

Refuses to kill core OS processes or itself, never blocks your gateway, DNS or trusted IPs, and logs every action it takes.

Plain files, light on disk

History is JSON lines per day in your home folder, older days compressed, one year kept, capped at 256 MB.

FAQ

Questions

Is it really zero dependencies?

Yes. No npm install, no node_modules. RigWatch uses Node's standard library plus tools already on your OS (PowerShell, perf counters, /proc). The two optional helpers for sensors and FPS are downloaded from their official releases and checked by SHA-256.

Is this a replacement for Wazuh?

For one personal machine, it covers the same ideas: rule levels, MITRE ATT&CK, file integrity, configuration assessment, compliance views and active response. It is not a multi-agent server for a fleet, and it does not use Wazuh's ruleset or code.

Will it slow down my games?

Typical cost on a 16-thread desktop is about 1% CPU and under 1 GB of RAM, most of it in the PowerShell helpers that read Windows counters and logs. You can pause live updates with one key, and the OBS overlay shows FPS without opening the full dashboard.

Why does it ask for admin on Windows?

Windows only lets administrators read CPU sensors, capture frames, read the Security log and add firewall rules. Click No and RigWatch still runs with everything that does not need admin. Prefer least privilege? Start it with --no-elevate.

Does anything leave my machine?

Only the two helper downloads on first run, a small latency probe (configurable or off), tools you run yourself, and, if you turn it on, a daily download of public threat lists. Nothing about you or your PC is sent.

How do I report a bug?

System → Collectors → Copy diagnostics (no host name, user name or paths), then open an issue on GitHub and paste it.
